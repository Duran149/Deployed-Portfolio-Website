Student's True Grading System

Role: Project Proponent / Lead System Developer

Problem Statement

Teachers often spend a significant amount of time manually recording scores and computing student grades. Manual computation may result in calculation errors, delays, stress, and misunderstandings regarding academic performance.

The Student's True Grading System is a proposed web-based and mobile-based educational platform designed to help teachers manage student records and automatically compute grades based on authorized grading criteria.

Technologies and Tools Used

HTML CSS JavaScript Python Django MySQL Flutter Firebase Figma GitHub

Key Contributions

  • Designed the overall concept of the Student's True Grading System.
  • Planned the database structure for teachers, students, subjects, classes, assessments, and grades.
  • Designed an automated grade computation process.
  • Planned teacher and student user accounts with different access permissions.
  • Designed a responsive web interface for computers, laptops, tablets, and smartphones.
  • Proposed a mobile application version for easier access.
  • Planned the integration of e-books and digital learning materials for enrolled subjects.
  • Designed the system to help organize academic records and reduce repetitive manual computation.

Outcome and Expected Impact

  • Faster and more organized grade computation.
  • Reduced risk of repetitive manual calculation errors.
  • Improved management of student academic records.
  • Reduced workload and stress associated with manual grade computation.
  • Easier access to digital learning materials and e-books for students.
  • Improved transparency and organization of academic information for authorized users.
  • Support for the digital transformation of the K to 12 educational environment.
