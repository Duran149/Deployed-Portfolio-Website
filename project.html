PROJECT 01

Student's True Grading System

Project Proponent / System Designer / Aspiring Full-Stack Developer

Problem Statement

Teachers may spend a significant amount of time manually recording student scores, computing grades, checking results, and preparing academic records.

Manual grade computation may cause delays, calculation errors, repetitive work, stress, and misunderstandings between teachers, students, and parents.

Technologies & Tools Used

HTML CSS JavaScript PHP MySQL Python Django Flutter Firebase VS Code GitHub

Key Contributions

  • Designed the concept of the Student's True Grading System.
  • Planned automatic grade computation for teachers.
  • Designed teacher and student user accounts.
  • Planned subject, assessment, score, and grading records.
  • Designed the system for possible website and mobile application use.
  • Planned organized access to academic information.

Outcome & Impact

  • Faster grade computation.
  • Reduced repetitive manual work.
  • More organized academic records.
  • Improved accuracy through automated calculations.
  • Supports teachers in managing student grades more efficiently.

Evidence / Sample Output

Prototype design, database structure, grading computation interface, screenshots, and future website or mobile application demonstration.

PROJECT 02

Digital E-Book Learning Platform

System Designer / Web and Mobile Application Developer

Problem Statement

Students need organized and accessible learning materials that can be available through supported digital devices.

Printed learning materials may be difficult to carry, organize, update, and access when students are outside the classroom.

Technologies & Tools Used

HTML CSS JavaScript PHP MySQL Flutter Firebase Cloud Storage

Key Contributions

  • Designed a digital learning platform for educational e-books.
  • Organized materials according to subject coverage.
  • Planned student access through different supported devices.
  • Designed an easy-to-use reading interface.
  • Planned integration with the Student's True Grading System.

Outcome & Impact

The platform can provide students with organized access to educational materials using supported devices such as smartphones, computers, laptops, tablets, and other compatible digital platforms.

Evidence / Sample Output

Sample e-book interface, subject categories, responsive website layouts, and mobile application prototype.
